# Lim Yan De — Portfolio

Live site: https://yande55.github.io

Computer Science student (IMGD, SIT/DigiPen, graduating May 2028) in Singapore. I build the systems underneath games and simulations: engine code, AI behaviour and the architecture that holds interactive worlds together.

## What is on the site
- **Mintybug** (live, solo): an AI interactive fiction platform at https://mintybug.ai. Next.js, TypeScript, Prisma, PostgreSQL, 5 AI providers with cost-optimised routing.
- **Oathbound** (team of 6): co-op RPG in a custom C++ engine. I wrote the maths libraries, enemy AI and save/load.
- **Precure Survivors** (team of 4): top-down survival shooter in a custom C++ engine. I built the state manager, player mechanics, collision and XP/leveling systems.
- **EcoLab** (capstone): Unity simulation tool with a separate C++20/23 simulation module.
