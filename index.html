// 01 — ABOUT

What I actually build

I'm a Computer Science student in the Interactive Media & Game Development programme at Singapore Institute of Technology / DigiPen. Most of what I do sits below the surface a player sees — state machines, collision systems, save/load pipelines, engine math libraries — the parts that decide whether a world actually behaves the way it's supposed to.

Outside coursework, I run Mintybug, a live AI interactive fiction platform I founded and built solo, from the database schema to the AI provider routing to the Stripe payouts. I like working across that whole range: low-level engine code on one end, shipped product on the other.

Precure Survivors

TEAM CODEFALL · CSD1451 · C++ / CUSTOM ENGINE

A top-down survival shooter with roguelike elements — dodge waves of enemies, level up, and fight a bullet-hell boss. As programmer on a 4-person team, I built the core architecture (state manager, global data structures, build optimization), player mechanics, the collision system, and the XP/leveling passive-skill system — 83 of the team's 226 logged hours, the highest workload on the team.

Oathbound

CSD2401 / CSD2451 · C++ ENGINE + UNITY · TARGETING STEAM

A co-op RPG where players team up to explore, fight, and complete quests together, built in a custom C++ engine with a Unity prototyping track. I built engine math/utility libraries (Mathf, Vec2Math, GridPosition, Vec3/Vec4/Mat3/Mat4) for grid-based mechanics and OpenGL rendering, plus enemy AI (patrol/chase state machine, line-of-sight, elemental weaknesses) and a JSON-serialized save/load system for combat and enemy persistence.

EcoLab

GAM300 CAPSTONE · GODOT + C++20/23 (GDEXTENSION)

A real-time educational simulation tool in Godot. Simulation logic is built as a standalone C++20/23 module exposed via GDExtension, kept separate from the UI layer so the underlying simulation stays testable and reusable outside the game engine itself.

Mintybug

FOUNDER · LIVE PRODUCT · NEXT.JS / PRISMA / POSTGRES

A live AI interactive fiction platform I founded and built solo: a two-sided marketplace where creators author reusable RPG templates and players generate unique AI-driven story playthroughs, across 8 languages. Full stack on Next.js, TypeScript, Prisma, and Neon Postgres, with 5 AI providers behind cost-optimized routing and prompt caching, and Stripe Connect handling creator payouts. Also shipped production observability (Axiom, PostHog) and filed a USPTO trademark for the platform.
